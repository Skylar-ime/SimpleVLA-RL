# 阶段A解读

日期：2026-09-25。检查点：Qwen2.5-VL-3B-Instruct，修订版`66285546d2b821cf421d4f5eb2576359d3770cd3`.

128场景的初始状态探针在包括模型加载在内的432.4秒内完成。它执行了128次采样尝试、128次重放检查和640个候选动作反事实，进行了896次诊断交互。没有无效的重置。所有重放距离差异均为零。

只有5/128次尝试的动作触及了物体。在所有640个反事实动作中，有20个产生了接触；只有8/128个场景的候选动作之间的即时进展差值大于2毫米。因此，这个探测器对物理上具有信息反馈的覆盖度较低。

结果条件下的老师改变了动作分布(平均总变异度数为0.119)但是，这本身并不能证明它有所改善。其平均概率加权的即时进步差异与无反馈学生相比为-0.0000185米；场景bootstrap 95%区间为[-0.0000537, 0.00000753]m. 区间包括零。二进制和中性提示也改变了分布。打乱只对10/128个记录的反馈元组进行了更改。(7.81%)虽然所有记录都有符合条件的跨剧集捐赠者。

结论：代码执行并反馈提示有效，但初始状态探查没有显示明显的教师优势。这并不证明SDPO无效：大多数行动没有接触，单步进展是一个有限的衡量标准。需要进行一个有界阶段B在线试点来测量反馈多样性，并比较结果/二元/打乱与冻结无反馈部署。昂贵的三种子最终研究不应自动从这些结果开始。

这是一个开发诊断。反事实结果不会被教师或学生反馈，也不会作为训练标签。最终测试分割尚未评估。
