# V6分组SDPO实验

V5 规定，因果结果文本会将本地 EMA 教师改变，但其一过渡批次没有相同状态的自动生成解决方案演示。V6 更接近于原始 SDPO 丰富的反馈结构：一个原始机器人观察产生多个策略候选，一个正向进展候选成为相同状态的自我演示，并且教师被提示该演示及其测量的结果反馈。

条件：

- `solution_only`: 原始的SDPO自我演示机制，不包括环境反馈。
- `solution_plus_binary`同样的自我演示，加上成功/失败的结果。
- `solution_plus_causal`同样的自我演示加上有控制的接触、运动、进展和明确的保留或修订解释。
- `solution_plus_causal_shuffled`同样的自我演示加上从另一个相同成功状态但相反结论的事件中借来的结果判断。

所有条件使用相同的Qwen2.5-VL政策，一步式分组滚动，温度`1.5`为了候选人的多样性，一个单独的LoRA EMA老师在速率`0.01`，缓存教师的logits在一次优化步骤之前，反向KL`KL(student || teacher)`，且无GRPO/BC动作损失。部署评估从未收到反馈。

机制门在训练前运行。它需要自动生成的解决方案，可衡量的教师变化从仅凭解决方案开始，并且在因果反馈、二元控制和随机控制中具有可测量的进步优势。
