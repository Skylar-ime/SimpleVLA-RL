  <section class="section">
    <div class="container main-container">
      <h3 class="title is-3 section-title">Abstract</h3>
      <div class="paper-box">
        <p>
          Most vision-language-action (VLA) models are reactive: they predict the next action from the current instruction and observation, implicitly assuming that the current observation fully specifies the action-relevant state. In embodied control, embodiment-specific factors such as camera-to-robot geometry, robot calibration, or systematic actuation bias are often hard to identify from a single observation. We propose <strong>Reflective VLA</strong>, which conditions each decision on a context of observation-action-consequence triplets. Each triplet records not only what the robot observed and executed, but also how the scene changed afterward, exposing the deployment-specific mapping from actions to observed effects. Across LIBERO, SimplerEnv-Bridge, LIBERO-Plus, LIBERO-Plus-Hard, and real-world cross-camera deployment, Reflective VLA improves generalization while preserving strong in-distribution performance.
        </p>
      </div>
    </div>
  </section>

      <div class="figure-grid method-figure-grid">
        <div class="figure-wrap method-main-figure">

          </p>

  <script>
    (() => {
      const carousels = document.querySelectorAll("[data-carousel]");
      const pageSize = () => {
        if (window.matchMedia("(max-width: 768px)").matches) return 1;
        if (window.matchMedia("(max-width: 1100px)").matches) return 2;
        return 4;
      };

      carousels.forEach((carousel) => {
        const cards = Array.from(carousel.querySelectorAll(".carousel-card"));
        const dots = carousel.querySelector(".carousel-dots");
        let page = 0;
        let pages = 1;

        const render = () => {
          const size = pageSize();
          pages = Math.max(1, Math.ceil(cards.length / size));
          page %= pages;

          cards.forEach((card, index) => {
            const visible = Math.floor(index / size) === page;
            card.classList.toggle("is-visible", visible);
            const video = card.querySelector("video");
            if (!video) return;
            if (visible) {
              video.play().catch(() => {});
            } else {
              video.pause();
            }
          });

          dots.innerHTML = "";
          dots.hidden = pages <= 1;
          for (let i = 0; i < pages; i += 1) {
            const dot = document.createElement("span");
            dot.className = i === page ? "carousel-dot is-active" : "carousel-dot";
            dots.appendChild(dot);
          }
        };

        render();
        window.addEventListener("resize", render);
        setInterval(() => {
          page = (page + 1) % pages;
          render();
        }, 7000);
      });
    })();
  </script>
